# Learning checklist

Before publishing this project under your name:

1. Run and exercise every feature.
2. Explain each Java class in your own words.
3. Trace one request from JavaScript through the controller, service, repository, and database.
4. Replace the sample records.
5. Implement at least one roadmap feature on a branch.
6. Add screenshots to the README.

Good starter issues: sorting by date, a follow-up field, controller integration tests, improved empty states, and PostgreSQL configuration.
